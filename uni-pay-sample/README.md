# uni-pay

[![](https://img.shields.io/badge/uni--app-插件市场-green.svg)](https://ext.dcloud.net.cn/plugin?id=1835)
[![](https://img.shields.io/badge/license-MIT-blue.svg)](https://ext.dcloud.net.cn/plugin?id=1835)

`uni-pay` 是由 DCloud 官方推出的基于 **uni-app** 和 **uniCloud** 的统一支付组件库。它旨在为开发者提供一套简单、统一且安全的支付接入方案。

## 🚀 特性

- **统一 API**：一套代码同时支持微信支付和支付宝支付，屏蔽平台差异。
- **全端支持**：覆盖 App（iOS、安卓、鸿蒙）、微信小程序、支付宝小程序、H5 等主流平台。
- **云端闭环**：结合 uniCloud 云对象/云函数，自动处理支付签名、异步回调及订单校验。
- **安全防范**：内置证书管理与签名验证逻辑，确保支付流程符合第三方支付安全标准。
